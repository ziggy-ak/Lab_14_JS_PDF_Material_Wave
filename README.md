# Интерактивное резюме с Material Wave и PDF

Лабораторная работа №14, дисциплина «Web-Технологии».

## Возможности
- Любой текст на странице можно редактировать прямо в браузере
- При клике на кнопку «Скачать PDF» появляется анимация волны
- Актуальная версия резюме сохраняется в PDF-файл
- Страница адаптируется под экраны разных размеров

## Как использовать
1. Открыть `index.html` в браузере
2. При необходимости отредактировать текст – изменения сохраняются на странице
3. Нажать «Скачать PDF» – файл загрузится на компьютер

Сервер, сборка и установка дополнительных программ не нужны.
